# Оновлення АМП XP до v1.7.2

## Що змінюється

Версія 1.7.2 зосереджена на UX рейтингу/серій, Telegram-серіях, опитуваннях і репрезентативних експортних документах. Структура production-БД **не змінюється** порівняно з v1.7.1.

### Основні зміни

- Telegram `🔥 Серії участі`: перегляд власної тижневої серії/суперсерії, рекордів, пропусків і самостійна заморозка на N днів із квартальною квотою 14 днів.
- Web `🏆 Рейтинг і серії`: компактна таблиця + окрема сторінка серій кожного учасника з редагуванням, заморозкою, історією і перерахунком.
- 6 ліг: Діамантова 1000–1499 XP, нова Легендарна 1500+ XP; ТОП-10 ліг відображається 3×2.
- У кнопках каталогу активностей Telegram показується XP.
- Multiple-choice опитування перемикає варіанти в одному повідомленні; web-конструктор варіантів став простішим.
- Розширені способи вимірювання для цілей та автоматичних бейджів.
- Підтвердження нового учасника доступне у web із збереженням approval-flow для звичайного admin.
- Список учасників події доступний у брендованих Excel і PDF (базовий; розширений — лише superadmin).
- Автоматичні PDF/Excel-звіти отримали поліпшене брендоване оформлення.

## Безпечне оновлення

1. Зробити `heroku pg:backups:capture` і завантажити dump локально.
2. Зберегти `.env` поза Git-каталогом.
3. Перенести `amp_bot_v172/` через `rsync`, виключивши `.git`, `.env`, `.venv`, `data`.
4. Виконати `pip install -r requirements.txt`.
5. Переконатися, що `VERSION.txt` і `app/version.py` показують `1.7.2`.
6. Виконати `python -m compileall -q app scripts` та `git diff --check`.
7. Commit і `git push heroku main`.
8. Перевірити `/health`, Heroku process і logs.

## Після deploy перевірити

- `🔥 Серії участі` у Telegram та заморозку 1–2 дні на тестовому профілі.
- `🏆 Рейтинг і серії`: 6 ліг, сітку 3×2, кнопку `⚙️ Детально`, окрему сторінку серій.
- Опитування з `multiple`: кілька виборів без створення нових повідомлень, потім `✅ Готово`.
- Каталог `⚡ Активності`: XP у кожній кнопці.
- Web-підтвердження pending-учасника.
- Базовий Excel/PDF списку учасників тестової події; sensitive exports — лише під superadmin.
- `📣 Розсилки`: аудиторія «Усі учасники зі статусом Активний».
