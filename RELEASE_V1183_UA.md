# АМПасадори v1.18.3 — форми, картки подій, відповіді Швидких XP

**База збірки:** наданий архів v1.18.2; включено виправлення імпорту журналу змін подій та налаштування відновлення резервної копії на PostgreSQL 18. Збірку НЕ розгорнуто на Heroku.

## Зміни

1. Для адміністративних POST-форм помилки перевірки, HTTP 400/409/422 та збої сервера показуються в самій формі; внесений текст/вибрані файли залишаються в формі. Кнопки блокуються тільки під час запиту. Враховано, яку саме кнопку дії натиснуто, і відповіді з вкладенням для завантаження. Авторизацію, CSRF і серверні перевірки не вимкнено.
2. Для створення та редагування події дата перевіряється на справжній календарний день, а час завершення — на те, що він пізніший за початок. Перевірка виконується під час введення, при виході з поля й перед надсиланням. Не змінено часового поясу чи модель події.
3. Картки подій однієї лінії вирівняно за висотою, зображення отримали зону 16:9, кнопки розташовуються внизу; для ключових форм, груп кнопок і календарних елементів застосовано відступи щонайменше 5 px. Реальна браузерна перевірка всіх 61 сторінок залишається переддеплойною задачею.
4. «Швидкі XP» → посилання «Відповіді учасників»: список за конкретним завданням, ім’я, варіант або текст, правильність, бали, час, неповні мініквізи. Сторінка на 50 учасників; використовує наявні таблиці та авторизацію керування модулем. Жодного нового збереження персональних даних не додано.
5. Реалізовано виправлення `record_field_changes` у створенні/редагуванні подій; для архіву v1.18.2 актуалізовано резервне копіювання на PostgreSQL 18 і його регресійні тести.

**Alembic head:** `20260925_0015`. Нових міграцій і перерахунку XP немає.

## Перевірки збірки

- `python -m scripts.production_preflight`
- `python -m compileall -q app scripts migrations tests`
- `node --check app/web/static/admin_forms.js`
- `node tests/js/test_admin_forms.js`
- `python -m pytest -q tests/test_v1183_admin_form_answers_ui.py`

Повний `pytest`, інтеграційні тести на PostgreSQL 16/18 та перевірка вебпанелі в браузері мають пройти у вашому GitHub Actions/стейджингу. У середовищі збірки немає `aiogram`, тому повний тестовий набір не виконувався.
