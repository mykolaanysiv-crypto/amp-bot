AMP XP v1.19.1 — deployment outline

1. git switch main && git pull --ff-only origin main
2. git switch -c release/v1.19.1
3. Copy full v1.19.1 artifact into repository without .git/.env/.venv.
4. python -m scripts.dependency_lock_check
5. python -m scripts.release_consistency_check
6. python -m compileall -q app scripts migrations tests
7. python -m scripts.production_preflight
8. python -m ruff check --select E9,F63,F7,F82 app scripts tests
9. python -m pip_audit -r requirements.lock --progress-spinner=off
10. python -m pytest -q --ignore=tests/integration
11. GitHub Production Gate must run PostgreSQL 18 integration, Alembic 0016 -> 0017, downgrade/upgrade, schema drift and restore-verified backup.
12. git add -A && git diff --cached --check
13. git commit -m "AMP XP v1.19.1 media storage and data lifecycle"
14. git push -u origin release/v1.19.1
15. Merge only after green PR gates.
16. Verify Heroku /health/live, /health/ready, version=1.19.1 and alembic current=20261008_0017.

S3 migration (ONLY after provider config and verified backup):
python -m scripts.migrate_media_storage dry-run
python -m scripts.migrate_media_storage copy
python -m scripts.migrate_media_storage verify
python -m scripts.migrate_media_storage switch

Rollback storage backend (DB bytes were intentionally retained):
python -m scripts.migrate_media_storage rollback

Never run destructive S3 cleanup as part of v1.19.1 deployment.
