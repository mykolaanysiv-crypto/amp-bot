AMP XP / «АМПасадори» v1.13.0.3 — QA REPORT
Дата: 16.09.2026
Реліз: Telegram Navigation & Web Localization Hotfix

1. Виявлені production UX-регресії
- `/menu` та активний `/start` не відповідали після Architecture Completion.
- `/smart` як slash-команда не був зареєстрований.
- reply-клавіатуру неможливо було примусово оновити через `/menu`, тому користувачі залишалися зі старим розміщенням кнопок.
- назви винагород обрізалися до 28 символів.
- у web-панелі лишалися окремі англомовні visible labels/internal codes.

2. Root cause
- `app/handlers/start_flow/common.py` знаходиться на рівні `app.handlers.start_flow`, але lazy import учасницького router facade був `from . import participant`. Під час виконання `/start`/`/menu` для активного профілю Python шукав `app.handlers.start_flow.participant`, якого немає. Startup import цього не ловив, бо import був lazy і виконувався лише у user flow.
- Smart Opportunities існували як модуль/кнопка, але `Command("smart")` не був прив'язаний.
- `rewards_keyboard()` застосовував `compact_button_text(..., max_chars=28)` до participant-facing entity title.
- Architecture/UI evolution залишила кілька historical English labels у templates/routes.

3. Виправлення
- `/start` + `/menu`: `from .. import participant`.
- `/smart`: BotCommand + handler + FSM navigation + help.
- `/smart` refresh-ить opportunity matches перед показом.
- reward buttons: `entity_button_text(...)`, без code-side truncation.
- web visible labels локалізовано українською; Notification Center використовує `label(...)` для known internal codes.
- user-visible `check-in window/manual override` wording у Event Operations перекладено.
- historical UI regression assertions оновлено на актуальні українські labels.
- production_preflight отримав v1.13.0.3 UX guards.
