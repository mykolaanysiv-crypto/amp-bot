QA ENVIRONMENT NOTE
-------------------
The sandbox itself does not have the production runtime packages `aiosqlite` and `aiogram`, and outbound package installation is unavailable. For the complete 118-test regression run, temporary test-only compatibility shims from `/tmp/testdeps` were added to `PYTHONPATH` so SQLAlchemy async SQLite tests and the limited aiogram exception imports used by the tests could execute.

The shims are NOT stored in the project tree and are NOT included in the release ZIP. `requirements.txt` remains the source of production dependencies (`aiogram`, `aiosqlite`, `asyncpg`, etc.).

In a normal local/CI environment, verify again with the real dependencies:

    pip install -r requirements.txt
    pytest -q
