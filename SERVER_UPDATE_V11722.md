# AMP XP v1.17.2.2 — Quick XP

## Що додано

- Новий participant-facing розділ **«⚡ Заробити XP»** у головному меню та хабі «🚀 Долучитися».
- Home показує рекомендоване коротке завдання, якщо воно доступне.
- Підтримані типи: **мініквіз**, **відео + контрольне питання**, **мініопитування**, **коротка текстова відповідь**.
- Нагорода: 1–5 XP за завдання; одне завдання можна виконати лише один раз.
- Тижневий cap для micro-XP: **15 XP** на учасника, щоб короткі завдання не витісняли реальні події/волонтерство/квести.
- Після виконання бот показує отриманий XP, загальний XP і кнопку «Ще способи заробити XP».
- Є історія «✅ Уже виконано».

## Адмінка

Новий розділ `/admin/quick-xp`:

- створення quick-XP challenge;
- тип, назва, опис, питання, варіанти, правильна відповідь;
- посилання на відео/матеріал;
- XP, орієнтовна тривалість, старт, дедлайн;
- активність / featured-home / sort order;
- редагування;
- статистика виконань та виданих XP;
- розсилка всім активним учасникам, які ще не виконали challenge.

## Захист від фарму

- DB unique constraint `challenge_id + user_id`;
- application-level idempotency + `IntegrityError` fallback;
- weekly cap 15 XP;
- quiz/video XP тільки після правильної контрольної відповіді;
- poll/comment — лише один completion на challenge;
- XP записується окремою категорією `quick_xp`.
