1. Перейдіть у робочу Git-папку:
cd ~/Downloads/amp_bot_v1103

heroku pg:backups:capture -a amp-bot-ver-1-5-0

3. Розпакуйте hotfix:
rm -rf /tmp/amp_bot_v11201
mkdir -p /tmp/amp_bot_v11201
unzip -q ~/Downloads/amp_bot_v11201.zip -d /tmp/amp_bot_v11201

4. Накладіть поверх робочої папки:
rsync -av --delete --exclude='.git' --exclude='.env' --exclude='.venv' --exclude='__pycache__' --exclude='.pytest_cache' /tmp/amp_bot_v11201/amp_bot_v11201/ ./

5. Перевірте:
cat VERSION.txt
grep -n "_bootstrap_lock" app/domain_services/bootstrap.py
cat Procfile

git add -A

git push heroku HEAD:main
