# AMP XP v1.20.3 — Interaction System

Версія: 1.20.3

- Card hover: small lift + border accent + shadow.
- Primary CTA: gradient, lift on hover, pressed state.
- Modal editor: standardised size determined by content; mobile width respects viewport.
- Tabs remain true ARIA tabs from v1.20.2 and never use anchor-scroll as app navigation.
- Help quick-start cards switch the target category directly rather than injecting a query into search.
- Reveal animations are progressive enhancement only and use IntersectionObserver.
- All critical form submissions remain server-side and protected by existing CSRF/permission checks.
