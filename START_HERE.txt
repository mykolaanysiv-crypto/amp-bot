Поточний production candidate: v1.12.1.2 — CI Compatibility & Emergency Alert Hotfix поверх v1.12.1.1.

Головна production-модель: GitHub main -> Production Gate (PostgreSQL 16) -> Heroku deploy. Не використовуйте прямий `git push heroku` для звичайних релізів.
