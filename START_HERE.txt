КЛЮЧОВІ ЗМІНИ
---------------
1. Event Operations Cockpit: одна сторінка події для зареєстрованих, черги/резерву, check-in, attended, XP і feedback.
2. Тут же: стан QR-сканера, check-in window, остання дія сканера та оператор.
3. Масові дії: оновити чергу/резерви, підтвердити всіх відмічених, після закриття вікна — масово «Не прийшов».
4. Reporting 2.0: точний timestamp Europe/Kyiv, потокові KPI та моментні KPI окремо.
5. Воронки реєстрації й участі, Data Quality і визначення показників у PDF/XLSX.
6. Звіт за ISO-тиждень; динаміка автоматично по днях/тижнях/місяцях.
7. Одна точка даних = KPI замість беззмістовного line chart.
8. Майбутні події не входять у фактичну attendance-аналітику навіть за помилкового legacy status.
9. Журнал доступу: колонка «Хто» більше не розриває слова.
10. Схема БД: 53 таблиці, без нової schema migration відносно v1.11.0.

ВАЖЛИВО
-------
- Перед deploy зробіть Heroku PostgreSQL backup.
- Не копіюйте .env у Git/ZIP.
- MONOBANK_TOKEN залишається тільки в Heroku Config Vars / локальному .env.
- WEB_SESSION_SECRET не змінюйте без потреби.
- Не очищайте production PostgreSQL: v1.11.1 працює поверх існуючої БД.
- Після deploy перевірте /health, Операційний центр події, звіт за тиждень/місяць і Журнал доступу.
