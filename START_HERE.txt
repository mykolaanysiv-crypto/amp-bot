АМП XP / «АМПасадори» v1.11.0
=================================

ПОЧНІТЬ З ЦЬОГО

Поточний реліз: v1.11.0 — UX & Conversion.
База: v1.10.4.1 Monobank Jar Sync Hotfix.

КЛЮЧОВІ ЗМІНИ
---------------
1. Реєстрація: progress, resume/restart, кнопкові відповіді, autocomplete населеного пункту, людські validation errors.
2. Воронка: start → consent → profile → submit → approved → first activity.
3. Чернетки незавершеної реєстрації шифруються через Fernet-ключ, похідний від WEB_SESSION_SECRET.
4. Feedback 2.0: micro-feedback + одне нагадування + conversion/response rate.
5. Telegram Home: Next Best Action замість блоку «Швидкі дії».
6. Новий порядок Telegram-меню; «Адмін-панель» — окремий нижній ряд лише за наявності доступу.
7. Operations Dashboard: сьогодні, увага, SLA, failed notifications, pending registrations, check-ins, no-show, feedback, funnel, data quality.
8. Monobank/sensitive hardening: no-store для /admin, безпечні помилки API, маскування донорських деталей не-superadmin користувачам.
9. Схема БД: 53 таблиці.

ВАЖЛИВО
-------
- Перед deploy зробіть Heroku PostgreSQL backup.
- Не копіюйте .env у Git/ZIP.
- MONOBANK_TOKEN залишається тільки в Heroku Config Vars / локальному .env.
- WEB_SESSION_SECRET не змінюйте без потреби: він використовується для захисту сесій і шифрування нових registration checkpoints.
- Release phase запускає штатний db.init/bootstrap; нові additive-поля/таблиці створюються автоматично.
- Після deploy перевірте /health, Telegram-реєстрацію, Feedback 2.0, Operations Dashboard та Monobank sync.
