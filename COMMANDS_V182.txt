AMP XP / АМПасадори v1.8.2 — КОМАНДИ ОНОВЛЕННЯ
================================================

1. ПЕРЕЙТИ У ПОТОЧНИЙ PRODUCTION-ПРОЄКТ

cd ~/Downloads/amp_bot_v155

git status


2. BACKUP POSTGRESQL ПЕРЕД ОНОВЛЕННЯМ

mkdir -p ~/Downloads/AMP_BACKUPS

heroku pg:backups:capture -a amp-bot-ver-1-5-0

heroku pg:backups -a amp-bot-ver-1-5-0

heroku pg:backups:download \
  -a amp-bot-ver-1-5-0 \
  -o ~/Downloads/AMP_BACKUPS/amp_before_v182.dump


3. РОЗПАКУВАТИ НОВУ ВЕРСІЮ

cd ~/Downloads

rm -rf ~/Downloads/amp_bot_v182

unzip ~/Downloads/amp_bot_v182.zip -d ~/Downloads/

cat ~/Downloads/amp_bot_v182/VERSION.txt

Має показати:
1.8.2


4. БЕЗПЕЧНО СКОПІЮВАТИ НОВИЙ КОД

rsync -av \
  --exclude='.git' \
  --exclude='.env' \
  --exclude='.venv' \
  --exclude='data' \
  --exclude='.pytest_cache' \
  --exclude='__pycache__' \
  --exclude='*.pyc' \
  ~/Downloads/amp_bot_v182/ \
  ~/Downloads/amp_bot_v155/


5. ЛОКАЛЬНА ПЕРЕВІРКА

cd ~/Downloads/amp_bot_v155

source .venv/bin/activate

pip install -r requirements.txt
pip install -r requirements-dev.txt

cat VERSION.txt
python -c "from app.version import APP_VERSION; print(APP_VERSION)"

python -m compileall -q app scripts tests

pytest -q tests/test_v181_features.py tests/test_v182_ui.py

# За наявності всіх runtime-залежностей також:
pytest -q

git diff --check

git status


6. COMMIT

git add -A

git diff --cached --check

git status

git commit -m "AMP XP v1.8.2 Participant 360 UI polish"


7. DEPLOY НА HEROKU

git push heroku main


8. ПЕРЕВІРКА ПІСЛЯ DEPLOY

heroku releases -a amp-bot-ver-1-5-0

heroku ps -a amp-bot-ver-1-5-0

curl -s https://amp-bot-ver-1-5-0-9632a1434a6d.herokuapp.com/health

heroku logs -n 200 -a amp-bot-ver-1-5-0

Очікувана версія /health:

- 8 KPI мають бути 4 картки + 4 картки.
- «🎯 Квести» та «⚡ Активності» мають бути окремими вкладками.
- Текст у таблицях не повинен накладатися/обрізатися.
- Вкладка XP містить історію XP.
