# Оновлення сервера до АМПасадори v1.10.4

## 1. Що входить у реліз

v1.10.4 розвиває v1.10.3 без видалення наявних даних. Основні зміни:

- окремий робочий екран **📝 Реєстрації** замість дублювання списку учасників;
- модуль **💙 Донати** у Telegram і вебпанелі;
- синхронізація банки Monobank через офіційний Personal Open API за наявності `MONOBANK_TOKEN`;
- публічна звітність про використання коштів із PDF/чеками/зображеннями;
- донатна аналітика, прив’язка транзакцій до АМП-коду та автоматичні бейджі;
- фото для **🌍 Можливостей**;
- точні агреговані значення в аналітиці для суперадміністратора, при цьому персональні списки вразливих категорій не формуються;
- виправлення темної теми, мобільних карток, блоку прав доступу та єдиний перемикач теми у правому верхньому куті;
- додаткова українізація назв та службових підписів інтерфейсу.

## 2. Перед оновленням Heroku

Зробіть резервну копію PostgreSQL:

```bash
heroku pg:backups:capture -a amp-bot-ver-1-5-0
heroku pg:backups -a amp-bot-ver-1-5-0
```

Не видаляйте `DATABASE_URL` і не створюйте нову базу. Міграції v1.10.4 additive/idempotent.

## 3. Нові змінні середовища

Публічне посилання на банку вже має безпечне значення за замовчуванням, але його можна явно задати:

```bash
heroku config:set DONATION_JAR_URL="https://send.monobank.ua/jar/5S531LWQuc" -a amp-bot-ver-1-5-0
```

Для автоматичного отримання балансу банки та транзакцій потрібен **особистий токен Monobank Open API власника банки**:

```bash
heroku config:set MONOBANK_TOKEN="ВАШ_СЕКРЕТНИЙ_ТОКЕН" -a amp-bot-ver-1-5-0
```

`MONOBANK_TOKEN` не можна додавати в Git, `.env.example`, повідомлення або скриншоти. Без токена кнопка банки та публічна звітність продовжують працювати, але автоматична синхронізація транзакцій вимкнена.

Перевірка змінних без виведення самого секрету:

```bash
heroku config -a amp-bot-ver-1-5-0
```

## 4. Деплой із чистого релізного ZIP

```bash
cd amp_bot_v1104

git init
git branch -M main
git add .
git commit -m "Deploy AMP v1.10.4"

heroku login
heroku git:remote -a amp-bot-ver-1-5-0

git push heroku HEAD:main --force
```

`--force` потрібен, якщо реліз розпаковано в нову Git-історію, а Heroku вже містить попередні коміти. Він замінює Git-історію коду застосунку, але сам по собі не очищає PostgreSQL.

## 5. Зміни схеми БД

Після запуску `db.init()` існуюча база отримує additive-поля/таблиці. Схема v1.10.4 містить **52 таблиці**.

Нові таблиці:

- `donation_jar_state` — останній відомий стан банки;
- `donation_transactions` — локальна історія синхронізованих транзакцій;
- `donation_reports` — записи публічної фінансової звітності;
- `support_page_views` — перегляди Telegram-сторінки підтримки.

Додатково:

- у `users` додаються поля модерації нових реєстрацій;
- у `opportunities` додається `image_path` для фото;
- наявні таблиці/історія XP/подій/учасників не видаляються.

## 6. Реєстрації

Новий екран **📝 Реєстрації** є вхідною чергою. Він показує очікування, схвалення за сьогодні та відхилення.

Після **✅ Схвалити** система:

1. переводить профіль зі стану очікування в активний;
2. фіксує перевірку адміністратором;
3. відкриває функції учасника;
4. надсилає Telegram-повідомлення;
5. журналює дію;
6. прибирає людину з черги «Реєстрації» та показує її в «Учасниках».

Відхилення вимагає причину.

## 7. Донати та Monobank

Telegram: **💙 Підтримати** → **💙 Відкрити банку Monobank** / **📄 Звітність**.

Вебпанель **💙 Донати** показує:

- поточний баланс і ціль банки, якщо їх повертає API;
- відсоток заповнення;
- загальну суму позитивних надходжень у локальній історії;
- найбільший і середній донат;
- кількість донатерів за доступними даними;
- збір по днях;
- перегляди сторінки підтримки та унікальних авторизованих користувачів;
- транзакції та зв’язок із профілем АМП;
- використані кошти й публічні документи звітності.

Важливо: Monobank показує лише ті дані про відправника, які реально повертає API. Якщо ім’я не передано, система його не вигадує.

Через обмеження Personal Open API перша синхронізація виписки охоплює **останні 31 день**. Після цього нові операції накопичуються локально, тому історія в АМПасадорах поступово стає довшою.

Для автоматичної прив’язки учасник може додати свій АМП-код до коментаря переказу. Адміністратор також може вручну зв’язати транзакцію з профілем.

## 8. Донатні бейджі

Системні правила:

- **Мій перший донат** — перша пов’язана позитивна транзакція від 50 грн;
- **Мажор** — разовий донат від 200 грн;
- **Мафіозі** — разовий донат від 500 грн;
- **Меценат** — разовий донат від 1000 грн;
- **Почесний спонсор АМП** — сумарні пов’язані донати понад 2000 грн;
- **Брюс Всемогутній** — сумарні пов’язані донати понад 5000 грн для АМПасадорської/staff ролі.

Правила системних донатних бейджів не редагуються звичайною формою бейджів, щоб випадково не зламати автоматичне нарахування.

## 9. Приватність аналітики

Для звичайних ролей поріг приховування малих значень категорій вразливості зберігається.

Суперадміністратор може бачити **точні агреговані числа**, зокрема значення 1–4. Навіть для суперадміністратора модуль агрегованої аналітики **не створює ПІБ/контакти/персональні списки** конкретної вразливої категорії.

Таке саме правило застосовано до періодних звітів.

## 10. Після деплою

```bash
heroku ps -a amp-bot-ver-1-5-0
heroku releases -a amp-bot-ver-1-5-0
heroku logs --tail -a amp-bot-ver-1-5-0
```

Перевірте:

1. `/health` повертає `version: 1.10.4`;
2. **📝 Реєстрації** та **👥 Учасники** є окремими екранами;
3. схвалення тестового профілю переміщує його до учасників;
4. **💙 Донати** відкривають правильну банку;
5. при наявному `MONOBANK_TOKEN` кнопка «Оновити дані» синхронізує банку без помилки;
6. транзакцію можна зв’язати з АМП-кодом;
7. звіт із PDF/чеком відкривається з Telegram;
8. можливість із фото відображає фото;
9. у темній темі блок видалення читається нормально;
10. на мобільній ширині картки не виходять за межі екрана;
11. у шапці залишається один перемикач теми;
12. блок прав доступу після збереження повертається у закритий стан.

## 11. Важливо для фінансової звітності

Перед публікацією чека, рахунку або PDF перевіряйте документ на зайві персональні дані. Завантажені як публічні документи звітності доступні учасникам через Telegram.
