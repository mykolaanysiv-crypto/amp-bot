ЗМІНИ РЕЛІЗУ
1. Continuous Telegram QR Scanner
   - Telegram admin menu -> `📷 QR Scanner`;
   - кнопки подій стали Telegram Web App buttons;
   - після вибору події Mini App автоматично викликає native `showScanQrPopup`;
   - callback повертає false, тому scanner не закривається після одного QR;
   - debounce 2.2 сек для одного й того самого QR;
   - scan API: `/tg/event-scanner/{event_id}/scan`;
   - signed Telegram Mini App initData HMAC validation;
   - role check: coordinator/admin/superadmin;
   - existing idempotent attendance workflow використовується без дублю XP/годин;
   - unregistered participant -> durable chat receipt + callback `Зареєструвати та підтвердити`;
   - кожен scan -> durable chat receipt адміністратору з ПІБ, AMP-ID, event, registration/attendance state;
   - participant також отримує стандартне attendance повідомлення при першому підтвердженні.

2. Version update notification duplicate fix
   - `_announce_version_update` захищений DB distributed `job_lock`;
   - lock key includes APP_VERSION;
   - SystemSetting `last_announced_app_version` залишається другим idempotency guard;
   - concurrent startup processes більше не повинні створювати два однакові system broadcast campaign.
