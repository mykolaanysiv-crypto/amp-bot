AMP XP v1.6.4 — безпечне оновлення Heroku

1) Перейти до робочої папки:
cd ~/Downloads/amp_bot_v155

2) Перевірити стан Git:
git status

3) Зробити backup PostgreSQL:
heroku pg:backups:capture -a amp-bot-ver-1-5-0
heroku pg:backups -a amp-bot-ver-1-5-0
heroku pg:backups:download -a amp-bot-ver-1-5-0 -o ~/Downloads/amp_before_v164.dump

4) Перенести код v1.6.4 поверх чинної папки, не чіпаючи .git/.env/.venv/data:
rsync -av --exclude='.git' --exclude='.env' --exclude='.venv' --exclude='data' ~/Downloads/amp_bot_v164/ ~/Downloads/amp_bot_v155/

5) Активувати venv і встановити/оновити залежності (у v1.6.4 додано matplotlib для PDF-аналітики):
cd ~/Downloads/amp_bot_v155
source .venv/bin/activate
pip install -r requirements.txt

6) Перевірити код:
cat VERSION.txt
python -m compileall -q app scripts
git diff --check

Очікувана версія: 1.6.4

7) Додати зміни до Git:
git add -u
git add app/analytics.py app/web/templates/analytics.html app/web/templates/analytics_detail.html COMMANDS_V164.txt

git status

8) Commit:
git commit -m "AMP XP v1.6.4 automated analytics"

9) Deploy:
git push heroku main

10) Перевірити:
heroku ps -a amp-bot-ver-1-5-0
curl https://amp-bot-ver-1-5-0-9632a1434a6d.herokuapp.com/health
heroku logs --tail -a amp-bot-ver-1-5-0

Очікуваний health: {"status":"ok","version":"1.6.4"}

11) У браузері:
Cmd + Shift + R

Перевірити /admin/analytics, загальний Excel/PDF, окремі Excel/PDF та Telegram: 🛠 Адмін-панель → 📊 Аналітика.

ВАЖЛИВО:
- Не запускати повторно migrate_sqlite_to_postgres.py.
- v1.6.4 не додає нових таблиць БД: аналітика рахується з уже наявних даних.
- Перший production-запуск v1.6.4 автоматично надішле зареєстрованим Telegram-учасникам системне повідомлення про нову версію. Повторний restart тієї самої версії повідомлення не дублює.
