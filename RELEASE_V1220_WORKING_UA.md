# AMP XP v1.22.0 — інтеграційна робоча збірка (не production-ready)

## Статус
Це **повний архів вихідного коду** з розширеним UI-патчем поверх наданої v1.21.0. Назва не означає, що всі вимоги ТЗ завершено. VERSION.txt залишено без змін: це навмисно, щоб не сповіщати про ще не випущений реліз.

## Реалізовані зміни
- Спільне модальне створення записів (за наявності реальної форми на сторінці): квести, волонтерські задачі, можливості, опитування, швидкі XP, винагороди, бейджі, активності, завдання команди, цілі, розіграші, сезони, шаблони розсилок, звіти про донати, додавання запитань на детальній сторінці опитування.
- Відкриття наявних edit-details у діалозі. Виправлено lifecycle повернення DOM після закриття: той самий вузол повертається у початкове місце, edit-summary зберігається і може бути натиснутий повторно. Підтримано запит про підтвердження втрати незбережених даних.
- На рівні існуючих форм збережено серверні endpoint, action, method, CSRF, file upload, active listeners.
- Вже наявні перемикачі Quick XP quiz/video/poll/comment продовжують перемикати групи полів.
- Технічні повідомлення про релізи в broadcast_runtime.py поставлено у чергу лише для ACTIVE users з UserRole.SUPERADMIN, з dedupe за версією й користувачем.

## Що НЕ реалізовано і не слід вважати протестованим
- Не завершено повний page-by-page редизайн усіх ~90 сторінок із Design Bible.
- Не додано нових серверних форматів Quick XP, окрім наявних quiz/video/poll/comment.
- Не проведено browser Playwright E2E/visual QA у Safari/Chrome; селектори нових форм потрібно перевірити на реальній сторінці кожної ролі.
- Не перевірено PostgreSQL 18, Telegram live, Heroku smoke, CI, backup/restore.
- `pytest tests/test_broadcast_retry_schema.py` не збирається через відсутній `aiosqlite` у цьому середовищі.
- Майбутні / вже queued outbox-повідомлення старої широкомовної розсилки потребують окремого аудиту перед розгортанням.
- Потенційно page-specific JavaScript може спиратися на попереднє DOM-розташування форм; перевірити всі створення та редагування до деплою.
