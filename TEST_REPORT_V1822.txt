AMP XP / «АМПасадори» v1.8.2.2 — QA REPORT
================================================

Purpose
-------
Emergency startup hotfix for v1.8.2.1 after Heroku dyno crash during FastAPI route registration.

Production error reproduced from supplied logs
----------------------------------------------
Route: POST /admin/events/{event_id}/scanner
Error: NameError: Fields must not use names with leading underscores; e.g., use 'csrf' instead of '_csrf'.
Cause: route signature contained `_csrf: str = Form("")`. FastAPI/Pydantic v2 creates a body model during startup and rejects field names beginning with `_`.

Fix
---
- Removed `_csrf` from the Python route signature.
- Browser still sends `_csrf` in FormData.
- CSRFMiddleware still reads form.get("_csrf") and validates it with compare_digest before the route executes.
- No CSRF weakening.
- No DB/schema/business-logic changes.
