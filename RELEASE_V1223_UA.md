# AMP XP 1.22.3 — особисті вебсповіщення, UX доробки

- Додана вебскринька персональних сповіщень для вебакаунтів із пов’язаним профілем учасника.
- Лічильник відображає реальні непрочитані записи, не Telegram-статуси доставки. Окремий облік прочитання за `account_id`.
- Позначення прочитаним захищене авторизацією, перевіркою власника і CSRF middleware.
- Нова міграція Alembic `20261011_0019` створює `web_notification_reads`; без застосування міграції вебскринька не працюватиме.
- Додаткові CSS-правила для інтерфейсу, темної теми, довгого тексту та мобільної адаптації.

## Обмеження
- Вебскринька використовує чинні записи `notifications`, адресовані `linked_user_id` персонального аккаунта. Це не універсальна система всіх адміністративних подій. Не прив’язані акаунти матимуть лічильник 0.
- Повноцінний QA усіх модальних вікон, Safari та наскрізна перевірка PostgreSQL 18, Telegram і XP/QR на цьому середовищі не гарантовані; результати перевірок наведені окремо.
- Не розгортати без перевірки Alembic та тестової БД.
