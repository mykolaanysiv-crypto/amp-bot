Реліз: Startup Import Hotfix

1. Причина
GitHub `python -m scripts.heroku_release` для v1.13.0.1 впав під час startup smoke на імпорті `app.main`:
ModuleNotFoundError: No module named 'app.handlers.time_utils'.

Коренева причина: після split `app.handlers.start` -> package `app.handlers.start_flow` relative imports рівня `..` почали резолвитись як `app.handlers.*` замість root `app.*`.

2. Виправлення
- `app/handlers/start_flow/common.py`: root imports переведено на `...`.
- `app/handlers/start_flow/entry.py`: `gamification` переведено на `...gamification`.
- `scripts/production_preflight.py`: додано generic AST guard для всіх explicit relative module imports у `app/`.
- `base.html`, `login.html`, `login_2fa.html`: asset cache token синхронізовано з 1.13.0.2.
- Додано `tests/test_v11302_startup_import_hotfix.py`.
