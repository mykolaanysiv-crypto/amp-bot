AMP XP v1.6.3 — безпечне оновлення Heroku

1) Увійти в Heroku та зробити backup PostgreSQL:
heroku login
heroku apps:info -a amp-bot-ver-1-5-0
heroku pg:backups:capture -a amp-bot-ver-1-5-0
heroku pg:backups:download -a amp-bot-ver-1-5-0 -o ~/Downloads/amp_before_v163.dump

2) Розпакувати отриманий amp_bot_v163.zip:
cd ~/Downloads
unzip -o amp_bot_v163.zip

3) Перевірити чинний Heroku Git-каталог (якщо він у вас ~/Downloads/amp_bot_v11):
cd ~/Downloads/amp_bot_v11
git status
git remote -v

ВАЖЛИВО: якщо git status показує незбережені зміни — зупиніться перед rsync і спочатку збережіть їх.

4) Зберегти локальний .env:
cp ~/Downloads/amp_bot_v11/.env ~/Downloads/amp_bot_v11/.env.before-v163

5) Перенести код v1.6.3, не чіпаючи .git/.env/.venv/data:
rsync -av --delete \
  --exclude='.git' \
  --exclude='.env' \
  --exclude='.venv' \
  --exclude='data' \
  ~/Downloads/amp_bot_v163/ ~/Downloads/amp_bot_v11/

6) Перевірити код:
cd ~/Downloads/amp_bot_v11
source .venv/bin/activate
python -m compileall -q app scripts
cat VERSION.txt

Має показати: 1.6.3

7) Додати Катерину Авдєєнко як admin. Скрипт сам створить пароль і покаже його один раз:
python scripts/add_staff_account.py \
  --app amp-bot-ver-1-5-0 \
  --username kateryna.avdieienko \
  --display-name "Катерина Авдєєнко"

8) Переглянути зміни:
git status
git diff --stat
git diff -- app/models.py app/db.py app/web/app.py app/web/templates app/web/static/admin.css

9) Commit та deploy:
git add .
git commit -m "AMP XP v1.6.3 cancellations templates update notices"
git push heroku main

НЕ запускати migrate_sqlite_to_postgres.py повторно.

10) Перевірити production:
heroku ps -a amp-bot-ver-1-5-0
curl https://amp-bot-ver-1-5-0-9632a1434a6d.herokuapp.com/health
heroku logs --tail -a amp-bot-ver-1-5-0

Очікуваний health: {"status":"ok","version":"1.6.3"}
Після перегляду логів: Ctrl+C.

11) Аварійний rollback за потреби:
heroku releases -a amp-bot-ver-1-5-0
heroku rollback vNN -a amp-bot-ver-1-5-0
heroku logs --tail -a amp-bot-ver-1-5-0
