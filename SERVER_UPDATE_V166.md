# AMP XP v1.6.6 — оновлення production

## Що додає версія
- автоматичне завершення квестів після дедлайну;
- виправлення web-layout волонтерських задач;
- коротші Telegram-кнопки без обрізання через три крапки;
- новий персональний QR-бейдж 55×85 мм, фото до 20 МБ, PNG і поширення;
- перетворення схвалених ідей на міні-проєкти;
- повноцінні звернення-кейси з нумерацією, перепискою та вкладеннями.

## Безпечне оновлення
1. Зробіть backup Heroku PostgreSQL.
2. Перенесіть файли v1.6.6 поверх чинної Git-папки, не замінюючи `.env`, `.venv`, `.git`, `data`.
3. Встановіть залежності з `requirements.txt`.
4. Перевірте `VERSION.txt`, `compileall` та `git diff --check`.
5. Commit і `git push heroku main`.
6. Release-ініціалізація БД сама додасть нові поля/таблицю. Не запускайте повторно SQLite→PostgreSQL migration.
7. Перевірте `/health`, Heroku logs, QR-бейдж, один тестовий кейс і одну схвалену ідею.
