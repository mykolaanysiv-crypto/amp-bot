# 9. Production smoke checklist
# - Web і worker = up.
# - Alembic current = 20260919_0007 (head).
# - Web → Гейміфікація → «Розіграші» відкривається.
# - Створити тестову чернетку з 1–5 типами подарунків і фото.
# - Перевірити аудиторію «Усі активні».
# - Перевірити аудиторію «Команда АМП».
# - Перевірити аудиторію «Учасники події».
# - Перевірити «Обрані ролі» та «Конкретні учасники».
# - У Telegram → Мій профіль є кнопка «🎲 Розіграші».
# - Participant бачить тільки активні розіграші, до аудиторії яких належить.
# - В automatic-режимі показується «береш участь автоматично» без кнопки подання.
# - У task-режимі без фото завершити подання неможливо.
# - Після тексту + фото Web показує заявку «На перевірці».
# - «Допустити» додає participant до пулу; «На доопрацювання» дозволяє повторне подання.
# - До дедлайну active draw не запускається без ручного «Закрити».
# - Якщо учасників менше за сумарну кількість подарунків, draw блокується.
# - Після draw кількість переможців = сумі quantity усіх подарунків.
# - Один participant не виграє два подарунки в одному draw.
# - Під кожним подарунком видно список його переможців.
# - Winner notification приходить через Telegram: назва розіграшу + подарунок + повідомлення, що адміністратор зв'яжеться.
# - Повторний POST/клік draw не створює новий набір переможців.
# - Проведений розіграш і подарунки не редагуються.
# - /health/ready і /health/dependencies без critical errors.
