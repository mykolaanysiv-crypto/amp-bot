# UI Visual Checklist — AMP XP v1.20.3

Перевірити на 320, 375, 390, 768, 1024, 1280, 1440, 1920px:

- Dashboard: hero contrast, KPI spacing, no overflow.
- Reports: every «Що включається автоматично» tile shows a real icon; no empty rounded icon boxes.
- Registrations: KPI + pending table use available width.
- Team AMP: responsibility controls aligned; table/actions have gaps.
- Events: calendar/meta icons visible; chips do not overlap; edit opens modal.
- Quests / Volunteer / Activities / Quick XP: semantic icons visible and card grids aligned.
- Opportunities: no overlapping actions; Share + Open are aligned; interested participants table readable.
- Surveys: metric chips show icons; descriptions do not collide with actions.
- Ideas: workflow fills available width and stages are readable.
- Leaderboard/Streaks: rule cards have spacing; tables use full width.
- Rewards: missing image renders AMP placeholder; edit/delete actions separated.
- Giveaways: gift/stat icons visible; prize form sections spaced.
- Seasons: creation form and history cards use width; date badges do not break by letters.
- Gamification 2.0 / Governance: panel headings have icons; spacing between modules is consistent.
- Broadcasts / Operations / Settings: action bars are aligned; no button clusters without gaps.
- Help Center: quick task click changes category directly; search field remains unchanged.
- Account: tabs work, modal widths are controlled, no accidental open modal.
- Light/dark themes: contrast and icon visibility.
