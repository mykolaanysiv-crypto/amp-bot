# AMP XP v1.6.7 — оновлення production

## Що змінено
- Повні назви в Telegram для подій, квестів, активностей, волонтерських задач та можливостей.
- Перебудовано списки: повна назва і ключова інформація показуються в тексті, кнопки — по одній у рядку без штучного обрізання.
- Головна назва персонального QR-розділу — `🎫 Мій QR-бейдж`; старий підпис підтримується лише для сумісності зі старими кешованими клавіатурами.
- Якщо натиснути стару кнопку `Мій QR-код`, бот оновить Reply Keyboard до актуального меню.
- База даних не змінюється.

## Безпечне оновлення
1. Зробити backup Heroku PostgreSQL.
2. Перенести файли v1.6.7 поверх чинної Git-папки, не замінюючи `.env`, `.venv`, `.git`, `data`.
3. Перевірити `VERSION.txt`, `app/version.py`, `compileall` і `git diff --check`.
4. Commit та `git push heroku main`.
5. Перевірити `/health` — має бути `1.6.7`.
6. У Telegram натиснути `/start` або `/menu`, щоб гарантовано отримати оновлену клавіатуру.
