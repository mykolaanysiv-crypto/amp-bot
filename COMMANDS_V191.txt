AMP XP / «АМПасадори» v1.9.1 — встановлення на Heroku
============================================================

1) Backup:
cd ~/Downloads/amp_bot_v155
heroku pg:backups:capture -a amp-bot-ver-1-5-0
heroku pg:backups -a amp-bot-ver-1-5-0

2) Розпакувати v1.9.1 у Downloads, потім оновити робочу папку:
rsync -av --delete \
  --exclude='.git' --exclude='.env' --exclude='.venv' --exclude='data' \
  --exclude='.pytest_cache' --exclude='__pycache__' --exclude='*.pyc' \
  ~/Downloads/amp_bot_v191/ ~/Downloads/amp_bot_v155/

3) Перевірка:
cd ~/Downloads/amp_bot_v155
source .venv/bin/activate
cat VERSION.txt
python -m pip install -r requirements.txt
python -m compileall -q app scripts tests
pytest -q tests/test_v181_features.py tests/test_v182_ui.py tests/test_v1821_calendar_event_ops.py tests/test_v1822_startup_hotfix.py tests/test_v1823_runtime_fixes.py tests/test_v1824_telegram_scanner.py tests/test_v1825_admin_menu_version_dedupe.py tests/test_v190_notification_center.py tests/test_v191_advanced_analytics.py

4) Git / deploy:
git status
git add -A
git diff --cached --check
git commit -m "AMP XP v1.9.1 Advanced Analytics"
git push heroku main

5) Production check:
heroku releases -a amp-bot-ver-1-5-0
heroku ps -a amp-bot-ver-1-5-0
curl -s https://amp-bot-ver-1-5-0-9632a1434a6d.herokuapp.com/health
heroku logs -n 200 -a amp-bot-ver-1-5-0
