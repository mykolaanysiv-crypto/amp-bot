АМП XP / «АМПасадори» v1.14.0 — Donations XP + Ambassador Cabinets

1. Перейти в Git-репозиторій:
cd ~/Downloads/amp_bot_v1103

2. Рекомендовано створити backup PostgreSQL перед schema update:
heroku pg:backups:capture -a amp-bot-ver-1-5-0

3. Розпакувати build:
rm -rf /tmp/amp_bot_v1140
mkdir -p /tmp/amp_bot_v1140
unzip -q ~/Downloads/amp_bot_v1140.zip -d /tmp/amp_bot_v1140

4. Накласти build поверх репозиторію, зберігаючи .git/.env/.venv:
rsync -av \
  --exclude='.git' \
  --exclude='.env' \
  --exclude='.venv' \
  --exclude='__pycache__' \
  --exclude='.pytest_cache' \
  /tmp/amp_bot_v1140/amp_bot_v1140/ ./

5. Перевірити версію:
cat VERSION.txt
# 1.14.0

6. Локальні перевірки:
python -m compileall -q app scripts tests migrations
python -m scripts.production_preflight
pytest -q tests/test_v1140_ambassador_donation_xp.py

7. Commit + push:
git add -A
git commit -m "Upgrade AMP to v1.14.0 donation XP and ambassador cabinets"
git push origin main

8. Після зеленого GitHub Actions/deploy:
heroku ps -a amp-bot-ver-1-5-0
heroku run -a amp-bot-ver-1-5-0 -- alembic current
# очікується 20260917_0003 (head)

9. Health:
curl -sS https://amp-bot-ver-1-5-0-9632a1434a6d.herokuapp.com/health/ready | python3 -m json.tool
curl -sS -o /tmp/amp_dependencies.json -w 'HTTP %{http_code}\n' https://amp-bot-ver-1-5-0-9632a1434a6d.herokuapp.com/health/dependencies
cat /tmp/amp_dependencies.json | python3 -m json.tool

10. Smoke:
- Telegram → Підтримати: видно «1 XP = 5 грн» і АМП-код.
- Виконати/ручну синхронізацію Monobank: старі локальні донати з АМП-кодом отримують пропущений XP тільки один раз.
- Профіль АМПасадора → Кабінет АМПасадора → Подати звіт.
- Web → АМПасадори: призначити напрям і переглянути звіт.
- Зареєструвати АМПасадора на подію → відкрити картку → «QR-код події».
- Публічна QR-картка АМПасадора показує статус і відповідальність.
