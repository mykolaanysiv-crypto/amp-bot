# AMP XP / «АМПасадори» v1.15.0 — Targeting, Event Analytics & Opportunity UX

v1.15.0 розширює адресність опитувань, аналітику подій, автоматичне сортування можливостей і правила роботи з кейсами/бейджами.

## Основне

- Опитування: доступ для всіх, обраних учасників або учасників конкретної події.
- Звіти: зрозуміла українська назва календарного тижня (понеділок–неділя).
- Події: окремий блок базової аналітики у картці події.
- Можливості: автоматичний порядок за актуальністю/дедлайном, неактивні внизу, 🔥 за 3 дні до дедлайну у Web і Telegram.
- Кейси: відповідальний лише активний Суперадмін, Адмін, Координатор або АМПасадор.
- Бейджі: редагування системних і АМПасадорських бейджів без зміни захищених системних правил.
