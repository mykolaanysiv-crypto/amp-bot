# AMP XP / «АМПасадори» v1.17.2.1 — Duplicate Management & Participant Status

## Що додано

- У **Data Integrity Center** групи дублікатів тепер показуються окремим керованим блоком із профілями, контактами, статусом і причиною збігу.
- Суперадміністратор може вибрати **основний профіль**, який потрібно залишити, та видалити інший профіль як дублікат.
- Видалення безпечне для історії:
  - якщо на дублікат немає FK-посилань — порожній запис фізично видаляється;
  - якщо є XP, attendance, заявки, документи чи інша історія — профіль переводиться в `deleted_permanent`, виключається з активних списків/повторних duplicate scans, але історичні зв’язки зберігаються.
- Перед видаленням система повторно перевіряє, що два профілі справді збігаються хоча б за телефоном, email або ПІБ + датою народження.
- Видалення доступне лише для ролей `participant` / `ambassador`; staff-профілі через Data Integrity Center не видаляються.
- Для небезпечної дії потрібно явно ввести `ВИДАЛИТИ`; операція журналюється як `web_duplicate_user_removed`.
- Якщо видалений дублікат спричинив реферальний бонус у межах чинного clawback-вікна, бонус коригується через існуючу idempotent referral-логіку.

## Зміна статусу учасника

- У списку **Учасники** суперадміністратор може одразу змінити статус без входу в детальну картку.
- Такий самий контрол доступний для кожного профілю в групі дублікатів Data Integrity Center.
- Дозволені прямі статуси: `pending`, `active`, `inactive`.
- `blocked` як і раніше керується модулем **Модерація**.
- `deleted` / `deleted_permanent` залишаються за окремими lifecycle/workflow правилами.
- Перехід в `active` синхронізує registration review/default team/referral readiness; перехід в `inactive` використовує існуючий referral clawback.
- Кожна пряма зміна журналюється як `web_user_status_direct_change`.

## UX

- `deleted_permanent` профілі більше не показуються в стандартному списку учасників без явного фільтра за цим статусом.
- Data Integrity Center пояснює різницю між фізичним видаленням порожнього дубліката та архівацією профілю з історією.
