# AMP XP v1.6.5 — оновлення production

## Що змінюється

Версія v1.6.5 додає автоматичні звіти, цілі/місії, streak, web-каталог можливостей, PNG-аналітику, статус `Неактивний`, перенесення/автозавершення активностей, скасування участі та глобальне виправлення Telegram FSM-навігації.

## База даних

Release-ініціалізація автоматично створює таблиці `goals`, `opportunity_interests` та відсутні поля для перенесення/можливостей. Міграція ідемпотентна: повторний release не дублює таблиці/колонки. Існуючі дані не треба повторно переносити з SQLite.

Перед deploy обов'язково виконайте:

```bash
heroku pg:backups:capture -a amp-bot-ver-1-5-0
heroku pg:backups:download -a amp-bot-ver-1-5-0 -o ~/Downloads/amp_before_v165.dump
```

## Безпечний deploy

Виконайте команди з `COMMANDS_V165.txt` по черзі. Не додавайте `.env` у Git і не запускайте `migrate_sqlite_to_postgres.py`.

Після deploy `/health` має повертати:

```json
{"status":"ok","version":"1.6.5"}
```

## Перевірка після запуску

1. Вебпанель → `📄 Звіти`: тестовий квартальний Excel/PDF.
2. `📊 Аналітика`: загальний PNG і PNG одного графіка.
3. `🌍 Можливості`: створити тестову можливість, перевірити `Мені цікаво` в Telegram.
4. `🏁 Цілі & місії`: створити тестову персональну ціль і перевірити прогрес.
5. Створити тестову подію/квест/задачу лише для себе, перевірити перенесення та автоматичне повідомлення.
6. Перевірити скасування власної участі.
7. У незавершеній формі `Запропонувати ідею` натиснути інший пункт головного меню: він має відкритися, а текст кнопки не повинен стати відповіддю форми.

## Автоматичне завершення

Фоновий lifecycle-процес працює кожні 5 хвилин. Подія вважається завершеною через 6 годин після часу початку (окремого end-time у моделі немає); квест/волонтерська задача — після дедлайну; прострочена можливість вимикається.

## Відкат

```bash
heroku releases -a amp-bot-ver-1-5-0
heroku rollback <ПОПЕРЕДНІЙ_RELEASE> -a amp-bot-ver-1-5-0
```

Відкат коду не видаляє нові nullable/сумісні таблиці та поля БД.
