AMP XP / «АМПасадори» v1.8.2.4 — ВСТАНОВЛЕННЯ НА HEROKU

ВАЖЛИВО: ZIP після розпакування створює папку ~/Downloads/amp_bot_v1824/
У rsync source має бути САМЕ ~/Downloads/amp_bot_v1824/

1. Перейти у production repo:
cd ~/Downloads/amp_bot_v155
git status

2. Зробити backup PostgreSQL:
heroku pg:backups:capture -a amp-bot-ver-1-5-0
heroku pg:backups -a amp-bot-ver-1-5-0

3. Розпакувати нову версію:
cd ~/Downloads
rm -rf ~/Downloads/amp_bot_v1824
unzip ~/Downloads/amp_bot_v1824.zip -d ~/Downloads/

Перевірити:
ls -la ~/Downloads/amp_bot_v1824
cat ~/Downloads/amp_bot_v1824/VERSION.txt

Очікувано:
1.8.2.4

4. Скопіювати код у production repo:
rsync -av --delete \
  --exclude='.git' \
  --exclude='.env' \
  --exclude='.venv' \
  --exclude='data' \
  --exclude='.pytest_cache' \
  --exclude='__pycache__' \
  --exclude='*.pyc' \
  ~/Downloads/amp_bot_v1824/ \
  ~/Downloads/amp_bot_v155/

5. Локальна перевірка:
cd ~/Downloads/amp_bot_v155
source .venv/bin/activate
cat VERSION.txt
pip install -r requirements.txt
pip install -r requirements-dev.txt
python -m compileall -q app scripts tests
git diff --check
pytest -q tests/test_v181_features.py tests/test_v182_ui.py tests/test_v1821_calendar_event_ops.py tests/test_v1822_startup_hotfix.py tests/test_v1823_runtime_fixes.py tests/test_v1824_telegram_scanner.py

6. Перевірити PUBLIC_BASE_URL:
heroku config:get PUBLIC_BASE_URL -a amp-bot-ver-1-5-0

Він має бути HTTPS, наприклад:
https://amp-bot-ver-1-5-0-9632a1434a6d.herokuapp.com

Якщо порожній або неправильний:
heroku config:set PUBLIC_BASE_URL=https://amp-bot-ver-1-5-0-9632a1434a6d.herokuapp.com -a amp-bot-ver-1-5-0

7. Commit:
git status
git add -A
git commit -m "AMP XP v1.8.2.4 continuous Telegram QR scanner"

8. Deploy:
git push heroku main

9. Перевірити production:
heroku releases -a amp-bot-ver-1-5-0
heroku ps -a amp-bot-ver-1-5-0
curl -s https://amp-bot-ver-1-5-0-9632a1434a6d.herokuapp.com/health
heroku logs -n 250 -a amp-bot-ver-1-5-0

Очікувано:
- /health version = 1.8.2.4
- web dyno = up

10. Smoke test QR Scanner:
- Telegram → Адмін-панель → 📷 QR Scanner.
- Натиснути активну подію.
- Mini App має відкритися, QR-камера — запуститися автоматично.
- Просканувати 2-3 бейджі підряд БЕЗ закриття камери.
- Після кожного scan перевірити повідомлення в чаті бота.
- Registered participant: Зареєстрований = так, Відмічений = так.
- Unregistered participant: у чаті кнопка «Зареєструвати та підтвердити».

11. Перевірити дублювання повідомлення про версію:
Після успішного deploy НЕ треба вручну змінювати last_announced_app_version.
Повторний restart тієї самої версії не повинен повторно розсилати повідомлення.

Перезапустити для smoke test за бажанням:
heroku ps:restart web -a amp-bot-ver-1-5-0

Потім:
heroku logs -n 200 -a amp-bot-ver-1-5-0

12. Якщо є помилка:
heroku logs --tail -a amp-bot-ver-1-5-0

Rollback:
heroku releases -a amp-bot-ver-1-5-0
heroku rollback vXX -a amp-bot-ver-1-5-0
