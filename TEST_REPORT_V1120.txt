2. PostgreSQL / CI
------------------
До релізу додано GitHub Actions CI з PostgreSQL 16 service і окремим
integration smoke test. CI запускає compile/preflight, regression tests,
PostgreSQL integration tests, Alembic/release smoke та alembic current.

У поточному sandbox відсутні production/test залежності aiogram, aiosqlite
та asyncpg, тому повний історичний pytest і реальний PostgreSQL integration
run локально тут не заявляються як виконані. Відомі collection/fixture errors
у цій оболонці пов'язані саме з відсутніми пакетами, а не з assertion failures.
