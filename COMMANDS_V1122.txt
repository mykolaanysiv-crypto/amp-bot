АМПасадори v1.12.2 — Error & Time Hardening

1. Перейти у локальний Git-репозиторій:
   cd ~/Downloads/amp_bot_v1103

2. Рекомендований ручний backup перед production deploy:
   heroku pg:backups:capture -a amp-bot-ver-1-5-0

3. Розпакувати build:
   rm -rf /tmp/amp_bot_v1122
   mkdir -p /tmp/amp_bot_v1122
   unzip -q ~/Downloads/amp_bot_v1122.zip -d /tmp/amp_bot_v1122

4. Накласти build поверх репозиторію, зберігши local/git environment:
   rsync -av \
     --exclude='.git' \
     --exclude='.env' \
     --exclude='.venv' \
     --exclude='__pycache__' \
     --exclude='.pytest_cache' \
     /tmp/amp_bot_v1122/amp_bot_v1122/ \
     ./

5. Перевірити версію:
   cat VERSION.txt
   # очікується 1.12.2

6. Локальні перевірки:
   python -m compileall -q app scripts tests migrations
   python -m scripts.production_preflight
   pytest -q tests/test_v1122_error_time_hardening.py

7. Commit + GitHub Production Gate:
   git status --short
   git add -A
   git commit -m "Upgrade AMP to v1.12.2 error and time hardening"
   git push origin main

8. Дочекатися зеленого GitHub Actions / deploy і перевірити formation:
   heroku ps -a amp-bot-ver-1-5-0
   # очікується web.1: up, worker.1: up

9. Alembic head (у v1.12.2 schema не змінюється):
   heroku run -a amp-bot-ver-1-5-0 -- alembic current
   # очікується 20260915_0002 (head)

10. Health:
   curl -sS https://amp-bot-ver-1-5-0-9632a1434a6d.herokuapp.com/health/ready | python3 -m json.tool
   curl -sS -o /tmp/amp_dependencies.json -w 'HTTP %{http_code}\n' https://amp-bot-ver-1-5-0-9632a1434a6d.herokuapp.com/health/dependencies
   cat /tmp/amp_dependencies.json | python3 -m json.tool

11. Worker log:
   heroku logs --dyno worker -n 160 -a amp-bot-ver-1-5-0

12. Ручний smoke:
   - Telegram → Події → відкрити подію / зареєструватися як у normal flow.
   - Перевірити check-in window у Event Operations Cockpit.
   - Web → Звіти → сформувати поточний місяць та короткий період.
   - Перевірити worker/scheduler heartbeat у Стані системи.
   - Переконатися, що JSON error logs (якщо з'являються) мають error_code/context.
   - Перевірити Notification Center та content views з v1.12.1.7.
