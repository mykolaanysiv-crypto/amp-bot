# AMP XP v1.22.6 — Design System Candidate

База: архівний повний source hotfix v1.22.5, **не підтверджений Git HEAD**.

Реалізовано: CSS-джерела зведено у штатний генерований `admin.css` (зокрема історичні модальні, UI та операційні стилі). Видалено їхні окремі активні HTTP-підключення. Додано семантичні токени і мобільні правила. Перемикач тем має циклічні стани System → Light → Dark, системна тема реагує на зміну ОС; початковий вибір застосовується до відображення.

**Статус:** кандидат, НЕ production-ready. Вимагає браузерного E2E-аудиту на усіх сторінках, адаптивних брейкпоінтах, браузерах, а також повного pytest, PG18, CI. Історичні тести, що вимагають окремих CSS link, мають оновлюватися після перевірки нової архітектури; бізнес-логіка сервера не змінювалася.
