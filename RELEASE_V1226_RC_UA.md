# AMP XP v1.22.6 — Release Candidate (14.10.2026)

**Статус:** RELEASE CANDIDATE; **НЕ production-ready**.

Повний вихідний код зібрано на основі наявного архіву `AMP_XP_v1.22.6_DESIGN_SYSTEM_CANDIDATE.zip`, що, зі свого боку, походить із v1.22.5 operations hotfix. Актуальний GitHub `main`, його SHA та стан production не верифіковані (мережевий доступ до github.com відсутній). Архів **не призначений для перезапису** актуальної директорії з Git на Mac без порівняння змін.

## Фактично внесено в цій ітерації

- Виправлено відсутній SVG-макрос `chevron-left` у навігації.
- Додано мобільний дзвоник персональних сповіщень; лічильники на desktop/mobile синхронізуються одним HTTP-запитом.
- Покращено діалогову семантику та керування скролом під час відкриття мобільної навігації.
- Створено спільні CSS-модулі `styles/components/controls.css`, `navigation.css`, `tables.css`, `styles/themes/dark.css`, `styles/responsive.css` та підключено в штатний `admin.css` через `scripts/build_admin_css.py`.
- Виправлено некоректний світлий фон у темному режимі; семантичні токени для поверхонь, тексту і контролів.
- Аудит: серверний пошук за виконавцем/дією/типом сутності, пагінація 40 записів, порожній стан, табличне/карткове відображення.
- Виправлено перекриття в мобільному журналі, спричинене історичним `min-width:720px`.
- Додано `scripts.build_admin_css --check` для перевірки відтворюваності бандлу.
- Оновлено застарілий тест, що вимагав інтервал polling 5000 мс замість 60000 мс.
- Додано 5 контрактних перевірок для навігації, сповіщень, журналу й CSS.

## Що лишається незавершеним

- Повна декомпозиція історичних CSS: окремі override-файли більше не завантажуються HTTP-ресурсами, але ще збираються в єдиний CSS разом з історичними правилами; численні `!important` залишаються.
- Повноцінні компоненти Jinja2 для **усіх** модулів і повний редизайн кожної темної сторінки.
- Реальні аутентифіковані браузерні сценарії для всіх адміністративних маршрутів та реальні мобільні пристрої.
- Перевірка фактичних записів `/admin/audit` в production, PostgreSQL пулу, Telegram та операційного контролю.
- Повний Python pytest, інтеграція PostgreSQL 18, резервне відновлення, GitHub Actions, перевірка `main` та production.

**Не змінено Alembic head:** `20261011_0019`. Міграцій для CSS/UX не потрібно.
