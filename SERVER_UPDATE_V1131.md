# AMP XP / «АМПасадори» v1.13.1 — Profile, Badges & Analytics UX

## Що виправлено та додано

- Виправлено кнопку **⚡ XP** у Telegram → «Мій профіль». Причина: після Architecture Completion історія XP зверталася до неіснуючого `XPTransaction.reason`; canonical поле — `description`.
- Автоматичне отримання бейджа тепер створює повідомлення через Notification Center: «🎉 Вітаємо! Ви отримали новий бейдж», назва бейджа, причина отримання та кнопка переходу до бейджів.
- Ручна видача бейджа також має єдиний вітальний формат повідомлення.
- Розділ **🏅 Бейджі** спрощено до двох головних дій: **Усі бейджі** та **Мої бейджі**. У каталозі видно, які бейджі існують, умови отримання та які вже здобуті.
- Якщо в учасника активна суперсерія, біля ПІБ у профілі показується 🔥. Для справді анімованого inline emoji підтримано optional Heroku Config Var `TELEGRAM_FIRE_CUSTOM_EMOJI_ID`; без нього використовується звичайний 🔥.
- Вирівняно fixed top search із реальною шириною sidebar на 1024–1365, 1366–1919 та 1920+ px; нормалізовано відступи між основними картками/блоками.
- У **Аналітиці** клік по графіку на загальній сторінці відкриває детальний агрегований показник.
- На detail page суперадміністратор може натиснути точку графіка або рядок таблиці й побачити: вид агрегованих даних, групу/категорію, значення та додаткове поле. Персональні ПІБ/контакти не розкриваються.
