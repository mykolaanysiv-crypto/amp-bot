Streak:
- streak.freeze_limit_quarter -> participant/web freeze logic;
- streak.super_total_misses + streak.super_consecutive_misses -> super-streak lifecycle;
- streak.badge_days -> badge threshold and notifications.

Events:
- events.reminder_minutes -> event reminder scheduler;
- events.feedback_delay_minutes -> post-event feedback scheduler;
- events.waitlist_reservation_minutes -> waitlist reservation expiry.

Privacy:
- privacy.suppression_threshold -> analytics + reporting aggregation threshold;
- privacy.retention_days -> persisted privacy policy value. Default 0 preserves the current non-destructive audit/history model; v1.10.0 does not physically delete participant history.
