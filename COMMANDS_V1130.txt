АМПасадори v1.13.0 — Architecture Completion

1. Перейти у локальний Git-репозиторій:
   cd ~/Downloads/amp_bot_v1103

2. Рекомендований ручний backup перед production deploy:
   heroku pg:backups:capture -a amp-bot-ver-1-5-0

3. Розпакувати build:
   rm -rf /tmp/amp_bot_v1130
   mkdir -p /tmp/amp_bot_v1130
   unzip -q ~/Downloads/amp_bot_v1130.zip -d /tmp/amp_bot_v1130

4. Накласти build поверх репозиторію, зберігши Git/local environment:
   rsync -av \
     --exclude='.git' \
     --exclude='.env' \
     --exclude='.venv' \
     --exclude='__pycache__' \
     --exclude='.pytest_cache' \
     /tmp/amp_bot_v1130/amp_bot_v1130/ \
     ./

5. Перевірити версію:
   cat VERSION.txt
   # очікується 1.13.0

6. Локальні перевірки:
   python -m compileall -q app scripts tests migrations
   python -m scripts.production_preflight
   pytest -q tests/test_v1130_architecture_completion.py
   pytest -q tests/test_v11217_content_views_event_ux.py tests/test_v1122_error_time_hardening.py

7. Перевірити зміни перед commit:
   git status --short

8. Commit + GitHub Production Gate:
   git add -A
   git commit -m "Upgrade AMP to v1.13.0 architecture completion"
   git push origin main

9. Дочекатися зеленого GitHub Actions / deploy і перевірити formation:
   heroku ps -a amp-bot-ver-1-5-0
   # очікується web.1: up, worker.1: up
