# АМПасадори v1.18.4 — вирівнювання вебпанелі та відповіді «Швидких XP»

**Тип релізу:** UI/UX hotfix поверх v1.18.3. Нових таблиць чи міграцій БД немає.

## Що змінено

1. **«Швидкі XP»**: «Відповіді» є окремою видимою основною дією картки. Лічильник враховує унікальних учасників як із завершеним завданням, так і з частковими відповідями мініквізу. Сторінка відповідей показує учасника, фактичну відповідь, правильність, XP та час.
2. **Картки та колонки**: усунено конфлікт глобального правила `.card + .card`, через який друга/третя картка в сітці могла починатися нижче. Сітки карток розтягуються рівномірно, а дії притискаються донизу картки.
3. **Зображення**: події, квести, можливості та винагороди використовують стабільні медіазони; розмір вихідного фото більше не змінює геометрію сусідніх карток.
4. **Сповіщення**: фільтри та кнопки «Застосувати» / «Скинути» мають окрему адаптивну сітку та однакову висоту.
5. **Українська локалізація**: замінено видимі службові англомовні назви `Change Control`, `Data Integrity Center`, `retention cleanup`, `privacy-retention scheduler`, `Old → New`, `Staff-профіль` тощо.
6. **Відступи**: для основних структурних груп вебпанелі закріплено мінімальний ритм від 5 px; стандартні робочі відступи — 8/12/18 px.

## Сумісність

- Версія: `1.18.4`
- Alembic head: `20260925_0015`
- PostgreSQL backup verification: PostgreSQL 18 / `postgres:18 pg_restore`
- Нової міграції немає; перерахунок XP не потрібен.

## Перевірки збірки

У середовищі складання успішно пройдено:

- `python -m compileall -q app scripts migrations tests`
- `python -m scripts.production_preflight`
- `python -m pytest -q tests/test_v1184_ui_hotfix.py tests/test_v1183_admin_form_answers_ui.py tests/test_v11215_backup_verification_hotfix.py tests/test_v1172_privacy_data_integrity.py`
- синтаксичний розбір 61 Jinja-шаблону
- `node --check app/web/static/admin_forms.js`
- `node tests/js/test_admin_forms.js`
- `bash -n scripts/verify_backup_restore.sh`

Повний `pytest` у локальному середовищі збірки не запускався до кінця, оскільки контейнер не має мережі для встановлення відсутнього `aiogram`. Повний неінтеграційний та PostgreSQL integration набір має пройти у GitHub Actions перед merge.
