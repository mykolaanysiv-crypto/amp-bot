ПРИМІТКА ПРО TEST ENVIRONMENT
-----------------------------
У sandbox немає встановлених runtime-пакетів aiogram/aiosqlite і немає мережевого доступу для pip. Тому повний pytest був запущений із ТИМЧАСОВИМИ test-only compatibility shims у `/tmp/testdeps`, які знаходяться ПОЗА release tree. Вони не копіюються у ZIP і не змінюють production requirements.

Production/локальне середовище має встановити реальні залежності через:
    pip install -r requirements.txt

У requirements.txt присутні реальні `aiogram`, `aiosqlite` і нова залежність `cryptography`.
