# Accessibility — AMP XP v1.21.0

Орієнтир: **WCAG 2.2 AA**.

Перевірки дизайну:
- visible focus;
- keyboard navigation;
- semantic headings/landmarks;
- accessible dialogs;
- real tab semantics;
- no color-only status communication;
- touch/click targets;
- contrast for glass/translucent surfaces;
- `prefers-reduced-motion`;
- buttons/tabs/chips do not split words.

Role-based UI не замінює permission checks: прихований navigation item не є security boundary.
