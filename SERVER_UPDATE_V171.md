# Оновлення АМП XP до v1.7.1

## Що змінюється

- `survey_questions.image_path` — фото/ілюстрація до питання опитування.
- нова таблиця `streak_freezes` — заморозки серій із квартальним лімітом 14 днів.
- нові web-експорти опитувань: Excel, PDF, PNG результату питання, деталі респондента.
- аналітика/звіти доповнені опитуваннями, бейджами по тижнях, лігами, серіями та заморозками.
- уніфіковано breadcrumbs, ширини, відступи та responsive-верстку нових web-секцій.

Міграція additive/idempotent. Повторний запуск `migrate_sqlite_to_postgres.py` НЕ потрібен.

## Безпечна послідовність

1. Зробити backup Heroku PostgreSQL.
2. Зберегти `.env` поза Git-папкою.
3. Перенести `amp_bot_v171` поверх робочої папки через `rsync` без `.git`, `.env`, `.venv`, `data`.
4. `pip install -r requirements.txt`.
5. Перевірити `VERSION.txt` і `app/version.py` → `1.7.1`.
6. `python -m compileall -q app scripts` та `git diff --check`.
7. Перевірити `git status`, додати код, commit, `git push heroku main`.
8. Release-ініціалізація сама створить `streak_freezes` і додасть `survey_questions.image_path`.
9. Перевірити `/health` → `1.7.1`, `heroku ps`, `heroku logs --tail`.

- `📋 Опитування`: створити питання з фото, пройти через Telegram, відкрити відповідь респондента.

- `🏆 Рейтинг і серії`: заморозити тестову серію на 1 день і перевірити використано/залишилось із 14 днів.

- `📄 Звіти`: сформувати Excel/PDF і перевірити гейміфікацію та бейджі по тижнях.
